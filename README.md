# Qlocky.UI
Qlocky is more than just an alarm clock — it’s a powerful, open-source smart device designed to enhance your entire daily routine. From the moment you wake up to how you manage your space and time throughout the day, Qlocky seamlessly combines intelligence, convenience, and control.

**Qlocky.UI** itself is the user interface which provides interaction with Qlocky.Device.

## 🔧 Tech Stack
- **Framework:** Qt 6 / QML  
- **Language:** Cpp17
- **Operating System:** Custom Linux Yocto [platform](https://github.com/Qlocky-Space/Qlocky.BSP)
- **Build System:** CMake  
- **Development Environment:** VS Code (recommended)
